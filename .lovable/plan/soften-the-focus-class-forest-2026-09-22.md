# Soften the Focus Class forest

## Changes
- Replace the heavy, dark edge trees with lighter slim trunks and sparse leafy canopies, keeping the timer area open.
- Brighten the evening palette toward calm blue-green tones with softer moonlight, mist, and distant depth.
- Keep only a few subtle fireflies, add occasional wind-blown leaves, and introduce rare slow rain as a purely visual weather moment.
- Preserve the existing Focus Class timer, sounds, presence, completion flow, and all other app behavior.

## Motion and comfort
- Use long, gentle animation cycles with no flashes or abrupt transitions.
- Make rain appear intermittently rather than continuously.
- Respect the existing reduced-motion preference so ambience stops for users who prefer less motion.

## Validation
- Check the active Focus Class on desktop and mobile for readability, uncluttered timer space, and calm motion.
- Run the project type check.
